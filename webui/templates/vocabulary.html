What happens when you press Save

  1. The text is checked first. If it is not a JSON object of text-to-text pairs, the save is refused and nothing on disk changes - a broken vocabulary file would silently switch off every correction on every later run.
  2. If it passes, {{ vocab.filename }} is replaced and the previous version is kept as {{ vocab.filename }}{{ backup_suffix }} (ADR-009: this is your typing, not a generated file).
  3. No pipeline step runs. Saving costs nothing and starts nothing. The next transcription picks the file up by itself.
